# 除冰调度仿真

降雪天气下,三架飞机在机坪等待除冰。玩家调度喷洒车、分配除冰顺序与用量,
在各自起飞窗口关闭前完成除冰并放飞,且不能发生二次结冰、不能让排水污染超标。

## 运行

- 游戏:直接用浏览器打开 `index.html`(或 `python3 -m http.server` 后访问)。
- 测试:`node test.js`,覆盖正常流程、设备故障、参数越限、风吹偏喷雾与确定性回放。

## 玩法

- 点选飞机,然后「派车前往」→「开始喷洒」(滑杆选择液量)→「允许起飞」。
- 喷太少:冰层除不净,无法起飞;喷太多:浪费液罐并加重排水污染(超标判负)。
- 风会把喷雾吹偏:风速越大,落到机身的比例越低,需要补喷。
- 除冰后防冰保持时间有限,降雪下超时未起飞会二次结冰,需要重新除冰。
- 泵故障时点击「维修泵」,修复后系统恢复安全状态。

## 仿真时钟与可重复性

- `sim.js` 为纯确定性核心:固定步长 `DT=0.1s`,种子化随机数,设备状态、
  环境(风/雪/阵风事件)与操作日志全部挂在同一仿真时钟上。
- 所有操作记入 `actionLog`,`DeiceSim.replay(seed, events, actionLog, tick)`
  可逐比特重建任意时刻状态(测试已验证)。
- 界面提供暂停 / 单步 / 恢复 / 失败回放(回放至失败 tick 后可单步检视)。
- 故障与越限发生时,日志记录发生时刻、当前余量(余液、污染余量、
  最近起飞窗口剩余、最大冰层)与系统响应;恢复后持续运行 60s 以上,
  由 `checkInvariants` 确认无隐藏连锁错误或状态跳变。

## Web Audio

首次点击操作按钮后启用:风声强度/音高随风速,引擎声随车速,喷洒有独立噪声通道。
