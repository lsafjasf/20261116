# 三组可重复测试参数

参数集中定义在 `src/core/demo.js` 的 `testParams()`，测试文件 `test/param-groups.test.js` 直接消费，保证可重复、无随机输入。

## 默认参数（正向主流程）

- 画布 480x360，背景 `#f4f6fa`；选择 `marker`，期望父链 `stage -> cardGroup -> grid -> marker`。
- 父对象 `cardGroup` 移动 `(+50,+25)`，子对象世界坐标同步偏移、本地坐标不变。
- 隐藏 `cardGroup` 后所有后代不可见，撤销恢复；删除 `badge` 后再撤销完整恢复。
- `t=30` 采样关键帧，`badge.x` 应为 `-40 -> 50` 的中点 `5`。
- 连续两次导出 PNG 字节一致；重载校验顺序/关键帧/坐标/颜色全部通过。

## 边界参数（极端但合法）

- 1x1 画布渲染；父对象零位移；透明度取 `0`；重排到下标 `0`。
- 采样时间 `t=0`（首帧之前取基础值）。
- `scaleX=0` 形成奇异矩阵，求逆必须显式抛错而不是产出 NaN 画面。

## 异常参数（非法输入）

- 选择/移动/隐藏不存在的 id、删除根节点 `stage`、负采样时间，均抛出明确错误。
- 非法颜色 `#12345`、透明度 `2` 被 `validateNode` 拒绝。
- 所有失败操作不得污染工程快照、不得写入撤销历史，工程仍可正常导出。

## 资源回退参数（`test/resource-service.test.js`）

- `network`/`timeout` 故障且有缓存：回退过期缓存并给出 warning。
- 故障且无缓存：回退内置占位图并给出 error，不返回空白。
- `corrupt` 响应与缩略图器崩溃：回退占位并附 `THUMBNAIL_FAILED` 提示。
- `invalidate()` 后强制重新校验，不继续展示未验证的旧内容。
