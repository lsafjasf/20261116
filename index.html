键盘快捷键

      
    
        
  • F 聚焦画布（画布焦点有粗色边框）
    • 
        
  • V R E L H 选择 / 矩形 / 椭圆 / 直线 / 平移工具
    • 
        
  • 方向键 移动光标；Shift+方向键 微调 1px
    • 
        
  • 空格 / 回车 开始绘制、结束绘制或点选元素；Esc 取消
    • 
        
  • [ ] 上一个 / 下一个元素，Esc 取消选中，Delete 删除
    • 
        
  • Alt+方向键 平移画布（任何工具下均可用）
    • 
        
  • + - 0 放大 / 缩小 / 重置缩放
    • 
        
  • Ctrl+Z / Ctrl+Y 撤销 / 重做
    • 
        
  • Ctrl+E 导出，对话框中 Esc 关闭并返回原焦点
